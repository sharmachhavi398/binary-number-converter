# Binary Number Converter

A responsive web application that converts numbers
between Binary, Decimal, Octal and Hexadecimal.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Convert between four number systems
- Validate user input
- Copy conversion results
- Responsive interface
