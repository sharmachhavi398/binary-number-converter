About Number Systems

Number systems are used to represent numbers in computers and digital electronics. This tool helps you convert numbers easily between four commonly used number systems.

Binary Number System

Binary uses only two digits: 0 and 1. Computers use binary to represent data.

Example: Binary 1010 = Decimal 10

Decimal Number System

Decimal uses ten digits, from 0 to 9. It is the number system we use in daily life.

Example: Decimal 10 = Binary 1010

Octal Number System

Octal uses eight digits, from 0 to 7.

Example: Decimal 10 = Octal 12

Hexadecimal Number System

Hexadecimal uses sixteen symbols: 0–9 and A–F.

Example: Decimal 10 = Hexadecimal A
